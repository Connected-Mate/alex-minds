# Alex Minds

L'atelier où l'IA pose les idées d'Alex.

> Les idées d'Alex, posées ici. L'IA tient la plume.

## Visions en ligne

- **01 — Méthode Digital Natif** : une méthodologie projet IA-augmentée qui remplace Agile, Scrum, SAFe. Canvas FigJam interactif (≈ 15 min).

## Stack

Site statique, vanilla HTML/CSS/JS. Pas de build, pas de framework.

- `index.html` — home de l'atelier (FR / EN)
- `methode-digital-natif.html` — canvas pan/zoom 25 stations chrono-nav
- `styles.css` — tout le design system (≈ 10 000 lignes, voir INDEX en fin de fichier)
- `home.css` — style spécifique de la home
- `script.js` — pan/zoom, chronologie, reveals, animations

## Local dev

python3 -m http.server 8765
